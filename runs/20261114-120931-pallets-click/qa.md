## Q: In one short paragraph: where does an Option resolve its default value, and which test file covers that?

An Option resolves its default in `Parameter.consume_value`, which is the last fallback after the command line, environment variable, and default_map (`src/click/core.py` L2558-2562, calling `self.get_default(ctx)`). `Option.get_default` (`src/click/core.py` L3222-3246) is overridden to resolve auto-derived defaults lazily via `_resolve_lazy_default`. `Option.consume_value` (`src/click/core.py` L3627-3652) wraps the base call to handle flag sentinels and prompts. The default-value tests are in `tests/test_defaults.py`, which has cases such as `test_basic_defaults` (L22), `test_flag_default_map` (L110), and `test_default_map_source` (L253). I did not open these test bodies, so I have not confirmed which of them exercise `Option.get_default` specifically. Some default-related tests also live in `tests/test_basic.py` (e.g. `test_datetime_option_default`, L683).
